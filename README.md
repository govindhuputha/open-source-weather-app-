# Backend Developer — Open Source Application Project
**Duration:** November 2023 - December 2023 | **Location:** Hydwrabad, Telanagana, India

## Project Overview
A lightweight, open-source backend web application engineered using the Flask framework. The platform efficiently communicates with third-party external REST APIs to fetch, parse, and handle real-time geo-weather metrics asynchronously under heavy concurrent loads.

## Key Engineering Achievements
* **Dynamic API Integration:** Built a lightweight web architecture using Flask to query external REST APIs, implementing efficient data extraction routines to achieve seamless, **sub-second data loading times**.
* **Asynchronous Routing Logic:** Designed clean backend API endpoints (`/api/weather`) and structured JSON data parsing pipelines capable of streaming highly responsive updates for up to **50 concurrent data simulations** simultaneously.
* **Open-Source Version Control:** Maintained professional version control protocols utilizing Git to track iterations, feature additions, and secure production-ready deployment workflows on GitHub.

## Technical Architecture Stack
* **Framework & Core:** Python 3.x, Flask
* **API Utilities:** Requests (REST APIs integration), JSON Web Parsing
* **Deployment/VC:** Git & GitHub Platform
